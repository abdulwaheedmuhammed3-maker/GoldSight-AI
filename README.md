GoldSight AI

A responsive, real-time XAUUSD forecasting and market-analysis platform for desktop and Android.

Technology Stack

- React, TypeScript and Vite
- TradingView Lightweight Charts
- Python FastAPI
- REST API and WebSockets
- PostgreSQL
- Progressive Web App (PWA)

Core Features

- Live gold price and candlestick updates
- Multi-timeframe chart analysis
- AI-assisted market forecasts
- Technical indicators and key price levels
- Forecast history and performance evaluation
- Responsive mobile and desktop interface
